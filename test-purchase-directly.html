2. Prueba de comando PowerShell

Copia y ejecuta este comando en PowerShell para probar directamente el API:

Invoke-RestMethod -Uri 'http://localhost:5001/api/health/ping' -Method Get

Si el servidor está funcionando, deberías ver una respuesta similar a:

status message
------ -------
ok pong

3. Prueba de Compra con PowerShell

Para una prueba completa de compra, ejecuta este script en PowerShell:

$ticketPrice = 1.5    # Precio por ticket en USD
$ticketQuantity = 10  # Número de tickets
$totalAmount = $ticketPrice * $ticketQuantity * 100  # Convertir a centavos

$purchaseData = @{
    fullName = "Usuario de Prueba"
    email = "test@example.com"
    whatsappNumber = "+1234567890"
    identificationNumber = "V-12345678"
    paymentAmount = $totalAmount
    paymentMethod = "Zelle"
    paymentReference = "TEST123456"
    raffleId = "649ab8f45cbb0d3f084c57a1"
    quantity = $ticketQuantity
}

$jsonBody = $purchaseData | ConvertTo-Json

Write-Host "Enviando solicitud de compra..."
Write-Host "Precio por ticket: $${ticketPrice}"
Write-Host "Cantidad: ${ticketQuantity}"
Write-Host "Total: $${ticketPrice * $ticketQuantity} (${totalAmount} centavos)"

try {
    $response = Invoke-RestMethod -Uri "http://localhost:5001/api/tickets/purchase" -Method Post -Body $jsonBody -ContentType "application/json"
    Write-Host "Respuesta exitosa:" -ForegroundColor Green
    $response | ConvertTo-Json -Depth 3
} catch {
    Write-Host "Error:" -ForegroundColor Red
    Write-Host $_.Exception.Message
    if ($_.ErrorDetails.Message) {
        $_.ErrorDetails.Message
    }
}

Nota: Esta prueba no incluye la carga de la imagen de comprobante de pago porque es más complejo de hacer con PowerShell. Puedes implementar esa parte más adelante.
