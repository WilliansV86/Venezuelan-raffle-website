Fix Instructions

Follow these steps to fix the admin panel raffles issue:

  1. Check if your admin token is valid using "Check Admin Token"
  2. Test both public and admin raffle endpoints
  3. If admin endpoint fails but public works, there's an authorization issue
  4. Try the "Apply Test Token" button to insert a working token for testing
  5. After testing, you can go back to the Admin Panel
